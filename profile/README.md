## Starting a Beyond Compare Session

Before beginning, identify the source and destination files or folders and confirm that you have permission to access them. Preserve important originals before performing merge or synchronization operations.

1. **Select the Inputs:** Choose the files or folders that need to be compared.
2. **Choose a Comparison Type:** Select the appropriate comparison method for the content.
3. **Inspect Differences:** Review highlighted changes, missing items, and mismatched content.
4. **Evaluate Changes:** Determine which differences are expected and which require attention.
5. **Merge or Synchronize:** Apply only the changes appropriate to the task.
6. **Validate the Result:** Review the updated files or folders and confirm that the intended content remains intact.

**Data safety note:** Keep backups of important files before merging or synchronizing. Only compare or modify materials you are authorized to access.
